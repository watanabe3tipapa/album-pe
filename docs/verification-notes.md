# 視覚確認メモ

実施日: 2026-08-20

## LP（`/`）

ローカル開発サーバーで表示を確認した。ヒーローの見出し、写真ビジュアル、LP作成の4ステップ、機能紹介、共有アルバムへ進む複数の導線、フッターが日本語で表示された。ファーストビューでは、主見出しと「アルバムをはじめる」CTA、および写真共有のイメージが収まり、デザイン崩れは確認されなかった。

## アルバム画面（`/albums`）

Cloudflare Accessの環境変数および認証トークンがないローカル環境では、アルバム一覧取得はブロックされ、写真やアルバム情報は表示されなかった。これは、公開LPと認証必須のアルバム機能を分離する意図どおりの挙動である。

> 実際の作成・共有・アップロード体験を行うには、Cloudflare Access、D1、R2のバインディングと環境変数を設定したデプロイ環境で確認する必要がある。
