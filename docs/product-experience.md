# Album PE プロダクト体験設計

## 目的

Album PE は、写真共有用のLPを自分で設計・公開するための考え方を学べるガイドであり、同時に、家族・友人・イベント参加者が実際に写真を集めて閲覧できる共有アルバムである。LPは機能の紹介で終わらせず、読者が「つくる」「招待する」「写真を集める」という行動をすぐ開始できる構成とする。

## LPの構成

| セクション | 伝える内容 | 主な行動 |
| --- | --- | --- |
| ヒーロー | 写真をひとつの居場所に集め、招待した人とだけ共有する価値 | 「アルバムをはじめる」からアプリへ移動 |
| 解説 | 共有アルバムLPに必要な、目的・導線・安心設計・運用の4要素 | 読み進めて設計の要点を理解 |
| つくり方 | 1. 誰と共有するか決める、2. アルバムを作る、3. 招待して写真を集める、4. 思い出を残す、の4ステップ | 最終ステップでアプリを利用開始 |
| 使える機能 | アルバム作成、複数写真アップロード、グリッド表示、管理者による削除 | 実際の体験を具体化 |
| CTA | 読了後の次の一歩を明確化 | `/albums` へ遷移 |
| フッター | プライバシーの前提、画像素材のクレジット、アプリへの補助導線 | 必要に応じてアプリへ遷移 |

## 画面と導線

| 画面 | 役割 | 遷移 |
| --- | --- | --- |
| `/` | 学びと開始を両立するLP | `/albums` |
| `/albums` | 自分が所有するアルバムの一覧、アルバム作成 | `/albums/:id` |
| `/albums/:id` | 写真の閲覧、複数アップロード、所有者による削除 | `/albums` |

> LPは公開情報として誰でも読める。アルバムと画像を扱う画面・APIはCloudflare Accessで認証された利用者だけに提供し、サーバー側でもトークン検証と所有者確認を行う。

## 体験の要件

初回利用者は、LPの「アルバムをはじめる」から認証済みのアルバム一覧へ移動する。そこでタイトルと任意の説明を入力すると新しいアルバムが作られる。詳細画面ではドラッグ&ドロップまたはファイル選択で複数の写真を追加でき、進行状況・成功・失敗が画面上で分かる。作成者だけが削除でき、写真オブジェクトもメタデータと同時に削除する。

## コンテンツ・トーン

落ち着いたネイビーと暖色のアクセントを用い、思い出を安全に集める温かさと、個人情報・写真を扱うサービスとしての安心感を両立させる。専門用語は避け、LP作成の要点を実行可能な言葉で説明する。
